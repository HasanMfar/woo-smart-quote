## بخش ۱ — مشتری و مدیر فروشگاه

### ۱.۱ نصب از پیشخوان وردپرس

1. با حساب مدیر وارد پیشخوان شوید.
2. **افزونه‌ها → افزودن افزونه → بارگذاری افزونه**.
3. فایل بسته (مثلاً `woo-smart-quote-1.0.0.zip` یا `woo-smart-quote.zip`) را انتخاب و **اکنون نصب کن** را بزنید.
4. بعد از نصب، **فعال کردن افزونه** را بزنید.
5. اگر پیام «افزونه نرخنگار برای فعالیت نیازمند نصب و فعال‌سازی ووکامرس است» دیدید، ابتدا ووکامرس را فعال کنید و دوباره افزونه را فعال کنید.
6. بعد از فعال‌سازی، منوی **نرخنگار** در نوار کناری پیشخوان ظاهر می‌شود.

### ۱.۲ ساخت برگه استعلام

1. **برگه‌ها → افزودن برگه**.
2. عنوان: «استعلام قیمت».
3. در محتوای برگه شورت‌کد زیر را قرار دهید:
   ```
   [woo_smart_quote_list]
   ```
4. انتشار. اگر از بلوک‌ها استفاده می‌کنید، یک بلوک «شورت‌کد» بسازید و همان متن را داخلش بگذارید.
5. بهتر است این برگه در منو و فوتر سایت لینک شود؛ ویجت شناور سبد استعلام هم به‌صورت خودکار در همه صفحات نمایش داده می‌شود.

### ۱.۳ تنظیمات اولیه (حدود ۵ دقیقه)

منوی **نرخنگار**، برگه‌های تنظیمات:

| برگه | چه چیزی را تنظیم می‌کند |
| --- | --- |
| **داشبورد استعلام‌ها** | فقط نمایش آمار؛ تنظیمی ندارد و با باز شدن منو همین صفحه می‌آید |
| **تنظیمات و مشخصات PDF** | نام رسمی شرکت، شناسه ملی، کد اقتصادی، تلفن، نشانی، آدرس لوگو، مهر دیجیتال، مدت اعتبار پیش‌فاکتور، پانویس PDF |
| **پیام‌رسان‌ها** | توکن بازوی بله و ربات ایتا، شناسه‌های چت کارشناسان، قالب پیام متنی استعلام، دکمه «ارسال پیام تست» |
| **ارسال به خریدار** | ارسال خودکار پیش‌فاکتور با پیامک/بله/ایتا، انتخاب سرویس‌دهنده، کلید API، کد پترن، شماره خط ارسال |
| **ربات تعاملی و دریافت پیام** | ثبت/حذف وبهوک بله، فعال‌سازی پولینگ، چت‌های مدیر، متن خوش‌آمد، قالب فهرست و کارت استعلام، صندوق ورودی پیام |
| **مسیریابی (Routing)** | ارسال استعلام هر دسته‌بندی محصول به چت کارشناس مربوط به همان دسته |
| **دکمه و ویجت شناور** | متن دکمه استعلام، نمایش در آرشیو، ویجت شناور، پنهان‌کردن دکمه خرید برای محصولات بدون قیمت |

**نکته مهم:** هر برگه با دکمه «ذخیره تمام تغییرات» جداگانه ذخیره می‌شود؛ برگه مسیریابی دکمه ذخیره اختصاصی خودش را دارد.

### ۱.۴ ارسال پیام تست و اولین استعلام

1. **نرخنگار → پیام‌رسان‌ها**: توکن و شناسه چت را وارد کنید و «ارسال پیام تست به بله» را بزنید. پیام «✓ پیام تست با موفقیت ارسال شد» باید در همان چت دیده شود.
2. یک محصول را باز کنید و «افزودن به لیست استعلام» را بزنید.
3. به برگه استعلام بروید، فرم (نام، ایمیل، موبایل) را پر کنید و ارسال کنید.
4. استعلام به‌صورت یک سفارش با وضعیت **Quote Request** ثبت و برای کارشناسان ارسال می‌شود.
5. در **ووکامرس → سفارش‌ها**، سفارش استعلام را باز کنید؛ در کادر «قیمت‌گذاری تفکیکی اقلام» قیمت هر ردیف را وارد و «ارسال پیش‌فاکتور» را بزنید.
6. وضعیت به **Quote Sent** تغییر می‌کند و پیش‌فاکتور PDF برای خریدار (ایمیل/پیامک/بله/ایتا) می‌رود.

### ۱.۵ ارتقا از نسخه قبلی (از دید مدیر فروشگاه)

1. از وضعیت فعلی سایت یک **پشتیبان کامل** بگیرید (اگر افزونه پشتیبان‌گیری دارید: دیتابیس + فایل‌ها).
2. **افزونه‌ها → افزودن افزونه → بارگذاری افزونه** و همان بسته جدید را انتخاب کنید.
3. وردپرس می‌پرسد «نسخه جدید موجود است، جایگزین شود؟» → **جایگزینی نسخه فعلی** را بزنید.
4. اگر افزونه غیرفعال شد، دوباره فعال کنید (یک بار غیرفعال/فعال کردن بعد از ارتقا، جدول پیام‌ها را هم به‌روز می‌کند و بی‌خطر است).
5. کش سایت و CDN را پاک کنید تا استایل جدید پنل و صفحه استعلام بارگذاری شود.
6. بعد از ارتقا این‌ها را ببینید:
   - **داشبورد استعلام‌ها** به‌عنوان صفحه پیش‌فرض منو (استعلام امروز/این هفته، صف بررسی، نرخ تبدیل، نمودار ۱۴ روزه).
   - نشان تعداد پیام خوانده‌نشده روی منوی نرخنگار و صندوق ورودی در برگه ربات.
   - کارت استعلام با نشان وضعیت در چت خریدار (`/orders`).
   - قالب‌های قابل ویرایش متن خوش‌آمد و کارت استعلام با توکن‌های `{name}`، `{order_number}` و… .

> ⚠️ **هرگز از دکمه «حذف» در صفحه افزونه‌ها برای ارتقا استفاده نکنید.** حذف افزونه، تنظیمات، پیام‌ها و فایل‌های PDF را پاک می‌کند. برای ارتقا فقط «جایگزینی نسخه فعلی» یا جایگزینی پوشه از طریق FTP.

## بخش ۲ — تیم فنی و نصاب

### ۲.۱ پیش‌نیازهای سرور

| مورد | حداقل | توضیح |
| --- | --- | --- |
| PHP | 7.2 | افزونه روی 8.1/8.2 تست شده است |
| افزونه‌های PHP | `gd`, `mbstring` (الزامی) و `xml`, `zlib` (توصیه‌شده) | mPDF برای تصویر، فونت و فشرده‌سازی منابع به این‌ها نیاز دارد |
| memory_limit | 128M | برای تولید PDF با لوگو و مهر دیجیتال 256M راحت‌تر است |
| دسترسی نوشتن | `wp-content/uploads` | پوشه `woo-smart-quote-pdfs` هنگام نیاز ساخته می‌شود |
| HTTPS | توصیه اکید | برای وبهوک بله و کوکی‌های خریدار لازم است |
| WP-Cron | فعال | پولینگ پیام‌ها و پاک‌سازی روزانه بر آن سوار است |
| دسترسی خروجی سرور | `tapi.bale.ai`، `eitaayar.ir`، `api2.ippanel.com`، `api.kavenegar.com` | برای ارسال پیام/پیامک؛ در صورت فایروال، دامنه‌ها را باز کنید |

### ۲.۲ نصب دستی (FTP/SSH)

```bash
# 1) پوشه را در مسیر افزونه‌ها قرار دهید
cd wp-content/plugins
unzip woo-smart-quote-1.0.0.zip          # پوشه woo-smart-quote/ ساخته می‌شود

# 2) مجوزها
find woo-smart-quote -type d -exec chmod 755 {} \;
find woo-smart-quote -type f -exec chmod 644 {} \;

# 3) فعال‌سازی
wp plugin activate woo-smart-quote
wp plugin list --name=woo-smart-quote --fields=name,status,version
```

اگر ووکامرس فعال نباشد، افزونه فعال می‌شود اما با پیام هشدار در پیشخوان کار نمی‌کند؛ ابتدا `wp plugin activate woocommerce`.

### ۲.۳ ارتقا روی نصب موجود

```bash
cd wp-content/plugins

# پشتیبان از نسخه فعلی (به‌جای حذف)
mv woo-smart-quote woo-smart-quote.bak-$(date +%Y%m%d)

# بسته جدید
unzip /path/to/woo-smart-quote-1.0.0.zip

# اجرای دوباره install() برای dbDelta (ساخت/به‌روزرسانی جدول پیام‌ها)
wp plugin deactivate woo-smart-quote
wp plugin activate woo-smart-quote

wp plugin list --name=woo-smart-quote --fields=name,status,version
wp cache flush
```

نکته‌ها:

- **داده‌ها دست‌نخورده می‌مانند:** سفارش‌ها، متای سفارش، تنظیمات (همه `wsq_*`) و جدول `{prefix}wsq_messages` حذف یا بازنویسی نمی‌شوند. تنها تغییری که ممکن است رخ دهد، `dbDelta` است که فقط ستون/ایندکس کم‌شده را اضافه می‌کند.
- **حذف از پیشخوان ممنوع:** `uninstall.php` در حذف افزونه اجرا می‌شود و تنظیمات، متای سفارش‌ها، جدول پیام‌ها و فایل‌های PDF را پاک می‌کند (سفارش‌ها حذف نمی‌شوند).
- اگر از object cache (Redis/Memcached) استفاده می‌کنید، بعد از ارتقا کش را خالی کنید تا نسخه جدید CSS/JS بارگذاری شود. دارایی‌ها با `WSQ_VERSION` نسخه‌بندی شده‌اند، بنابراین با بالا رفتن نسخه، کش مرورگر خودکار باطل می‌شود.
- در سایت‌های چندزبانه/چندسایتی، افزونه برای هر سایت جداگانه فعال و تنظیم می‌شود (تنظیمات با `get_option` هر سایت است، نه شبکه).

### ۲.۴ کارهای بعد از ارتقا (ترتیب پیشنهادی)

1. `wp plugin list` → نسخه درست فعال است؟
2. `wp cron event list | grep wsq` → رویدادهای `wsq_poll_updates` و `wsq_daily_cleanup` وجود دارند؟
3. `wp cron event run wsq_daily_cleanup` → بدون خطا اجرا می‌شود؟
4. **نرخنگار → پیام‌رسان‌ها** → «ارسال پیام تست» برای بله و ایتا.
5. **نرخنگار → ربات تعاملی** → وضعیت وبهوک (ثبت‌شده/حذف‌شده) و باز شدن صندوق ورودی.
6. یک استعلام واقعی ثبت کنید و کل مسیر تا PDF و وضعیت Quote Sent را ببینید.
7. **ووکامرس → وضعیت → زمان‌بندی‌شده‌ها (Scheduled Actions)**: گروه `woo_smart_quote` باید خالی از `failed` باشد.

### پوشه‌ها و فایل‌های تازه در این بسته

| مسیر | وضعیت | نکته |
| --- | --- | --- |
| `includes/class-wsq-stats.php` | **فایل جدید** | محاسبه آمار داشبورد؛ اگر این فایل کپی نشود، پنل با خطای `WSQ_Stats not found` بالا نمی‌آید |
| `assets/css/admin.css` | **بازنویسی‌شده** | استایل کارت‌های داشبورد، نمودار ستونی و نوار توزیع وضعیت |
| `assets/js/admin.js` | **به‌روزشده** | درج توکن در قالب‌ها، کپی شناسه، پاسخ صندوق ورودی |
| `lib/mpdf/` | **الزامی** | بدون آن PDF یا فارسی‌نویسی درست تولید نمی‌شود؛ در کپی دستی هرگز جا نیفتد (فونت‌های Vazirmatn داخل `lib/mpdf/fonts` هستند) |
| `templates/pdf/quote-fa.php` | **الزامی** | قالب پیش‌فاکتور |

**در بسته نصبی چه چیزی نباید باشد:** پوشه‌های توسعه‌ای مثل `ui-checks/`، `screenshots/`، `docs/`، فایل‌های `test-*.php`، فایل‌های zip قدیمی و لاگ‌ها. ریشه زیپ باید دقیقاً پوشه `woo-smart-quote/` باشد تا وردپرس آن را به‌درستی نصب کند.

### فایل‌هایی که عمداً از بسته حذف شده‌اند

| مسیر | دلیل حذف |
| --- | --- |
| `templates/pdf/gemini-code-*.php` | نسخه مرجع توسعه‌ای قالب PDF؛ هیچ کدی به آن ارجاع نمی‌دهد |
| `assets/fonts/` | کپی تکراری فونت Vazirmatn (نسخه اصلی در `lib/mpdf/fonts` است) و هیچ فایل CSS/JS به آن ارجاع نمی‌دهد |
| `lib/mpdf/**/.github/`، `phpstan*.neon`، `phpunit.xml`، `ruleset.xml`، `.gitignore` | فایل‌های توسعه و ابزار تحلیل ایستای کتابخانه mPDF؛ در اجرا استفاده نمی‌شوند |

## بازگردانی (Rollback)

1. افزونه را غیرفعال کنید (نه حذف).
2. پوشه فعلی را کنار بگذارید و پوشه نسخه قبلی را برگردانید:
   ```bash
   cd wp-content/plugins
   mv woo-smart-quote woo-smart-quote.failed-$(date +%Y%m%d)
   mv woo-smart-quote.bak-YYYYMMDD woo-smart-quote
   wp plugin activate woo-smart-quote
   wp cache flush
   ```
3. در صورت نیاز، دیتابیس را از پشتیبان بازگردانید. تغییرات دیتابیسی این افزونه فقط افزودنی است (جدول `wsq_messages` و آپشن‌های `wsq_*`)، بنابراین بازگشت به نسخه قبلی معمولاً بدون بازگردانی دیتابیس هم کار می‌کند.
4. پیش‌فاکتورهای تولیدشده در `uploads` باقی می‌مانند و مشکلی ایجاد نمی‌کنند.

## امنیت و داده‌ها

- توکن بله/ایتا و کلید API پیامک در جدول `wp_options` ذخیره می‌شوند؛ دسترسی به دیتابیس و پشتیبان‌ها را محدود کنید و از HTTPS استفاده کنید.
- صفحه‌های PDF با `.htaccess` از دسترسی مستقیم وب مسدود می‌شوند؛ نام فایل هر سفارش شامل یک بخش تصادفی (`_wsq_pdf_secret`) است.
- دسترسی به پنل افزونه فقط با قابلیت `manage_woocommerce` ممکن است.
- **حذف افزونه** (`uninstall.php`) این‌ها را پاک می‌کند: همه آپشن‌های `wsq_*`، ترنزینت‌ها، متاهای `_wsq_*` روی سفارش‌ها، جدول `{prefix}wsq_messages` و فایل‌های PDF. سفارش‌های استعلام حذف نمی‌شوند و با وضعیت خودشان در ووکامرس می‌مانند.
- برای ارتقا هرگز از «حذف» استفاده نکنید؛ فقط جایگزینی.
